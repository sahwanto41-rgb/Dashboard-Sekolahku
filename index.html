Panduan singkat

  1. Administrator: isi URL asli tiap aplikasi di kolom sebelah, lalu simpan.
  2. Kepala sekolah dan guru: klik BUKA APLIKASI pada kartu, atau pilih menu di kiri.
  3. Notula rapat: aplikasi keenam. Isi URL-nya seperti aplikasi lain.
  4. Statistik: angka hanya muncul setelah aplikasi sumber mengirim data lewat API. Isi URL data JSON dari Apps Script agar angka tampil. Sebelum itu tertulis Belum Terhubung.
  5. Pemasangan: unggah file ini ke hosting mana pun, atau bagikan tautan halaman ini.
  6. Hak akses dan login: masuk lewat akun tiap aplikasi. Login terpusat perlu server (lihat catatan pengembangan).
