Identitas, URL aplikasi, dan tautan

Panduan singkat

  1. Administrator: isi URL asli tiap aplikasi di kolom sebelah, lalu simpan.
  2. Kepala sekolah dan guru: klik BUKA APLIKASI pada kartu, atau pilih menu di kiri.
  3. KILAT dan MEKAR: URL sudah terisi bawaan. Ubah hanya jika alamat aplikasi berpindah.
  4. Statistik: MEKAR punya URL data JSON sendiri. KILAT memakai Web App Apps Script sendiri untuk data presensi murid.
  5. Statistik: angka hanya muncul setelah aplikasi sumber mengirim data lewat API. Isi URL data JSON dari Apps Script agar angka tampil. Sebelum itu tertulis Belum Terhubung.
  6. Pemasangan: unggah file ini ke hosting mana pun, atau bagikan tautan halaman ini.
  7. Hak akses dan login: masuk lewat akun tiap aplikasi. Login terpusat memerlukan server.

Pengaturan tersimpan di peramban perangkat ini saja. Kata sandi hanya mengunci tampilan pengaturan, bukan pengamanan data.
